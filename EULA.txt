6. WHAT THE SOFTWARE DOES

So that Your consent is informed, the Software:
  (a) captures the contents of each attached display in order to render the
      magnified overlay;
  (b) installs a system-wide low-level keyboard hook, used solely to detect the
      Esc key so the overlay can be dismissed from any window;
  (c) re-captures the contents of each display periodically so the overlay does
      not itself become a static image;
  (d) injects small synthetic mouse movements at regular intervals;
  (e) can ask Windows to keep the display and the system awake while the overlay
      is running, when You enable that option;
  (f) can change display brightness while the overlay is running, when You
      enable the dimming option, and restores the previous brightness when the
      overlay exits;
  (g) can register itself to start automatically when Windows starts, when You
      enable that option;
  (h) writes diagnostic messages to a text file inside its installation folder.

NO DATA LEAVES YOUR DEVICE. The Software works entirely offline. It does not
send any data over the internet, it opens no network connections, and it
contains no advertising, telemetry, analytics, or tracking of any kind. Captured
screen content, keystrokes, and diagnostic logs never leave Your device.
